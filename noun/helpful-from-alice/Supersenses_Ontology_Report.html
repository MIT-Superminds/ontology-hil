1. Tree branch vs supersense quadrants

Each item sits under one of four children of Entity (Information, Actor, Activity via process, Physical Entity). Independently, its noun.* tags map into the same four quadrants using supersenses-highlevel.json. We flag items where the tree quadrant is not supported by any mapped supersense, or only unmapped tags (e.g. noun.Tops) appear. Items under [added] Unclassified are not scored here. 3000 nodes under the main four branches align (tree quadrant appears in the supersense-derived set).
